# Сценарій демонстрації для вчителя

Покроковий перелік того, що можна показати вчителеві в поточній версії «Щоденника учителя»: на якій сторінці, що зробити і що має з’явитися на екрані. Документ складено за специфікацією (`docs/specs/specification.md`) і звірено в браузері з робочою версією 7 жовтня 2026 р. (остання зміна в ній — «Зберегти» доступна лише тоді, коли є що зберегти).

Адреси сторінок нижче вказано відносно адреси застосунку — локально це `http://localhost:3000`.

---

## 1. Підготовка (робить той, хто проводить демонстрацію)

```sh
cp .env.example .env          # і задати BETTER_AUTH_SECRET: openssl rand -base64 32
npm install
docker compose up -d          # база даних PostgreSQL
npm run db:migrate            # створити таблиці
npm run db:seed               # демо-вчителька та готовий набір даних
npm run dev                   # http://localhost:3000
```

Поки `BETTER_AUTH_SECRET` має значення `replace-me`, увійти не вийде.

**Демонстрація на сервері** (стек `docker-compose.prod.yml`). Облікові записи там створює команда, описана в `README.md` («Deploying to the VPS»). Штатного способу покласти демо-дані на сервер немає: сценарій демо-даних навмисно не входить до робочого образу, тому показ із розділів 5–9 проводять локально.

**Що кладе в базу `npm run db:seed`** (докладно — `docs/architecture/design/expand-fixtures.md` §3):

| Що | Значення |
|---|---|
| Вчителька | «Ковальчук М. І.», пошта `demo@teachers.local`, пароль `demo-password-1` |
| Навчальний рік | 1 вересня 2026 — 31 травня 2027, починається з чисельника |
| Семестри | І: 1.09.2026 — 24.12.2026; ІІ: 12.01.2027 — 31.05.2027 |
| Неробочі дні | 14 жовтня — «День захисників і захисниць України»; 26 жовтня — 1 листопада — «Осінні канікули» |
| Дні тижня без уроків | п’ятниця до осінніх канікул (методичний день); субота й неділя — весь рік |
| Дзвінки | уроки 1–5 починаються о 08:30, 09:25, 10:25, 11:20, 12:15; урок триває 45 хвилин |
| Відлік парності | від 1 вересня (чисельник) і повторно з 4 листопада (чисельник) |
| Тижневий розклад | «Мої уроки» — дві версії (зміна з 21 жовтня); «Уроки класу» 7-А — дві версії з проміжком 21 жовтня — 1 листопада |
| Правки окремих днів | 8 записів у жовтні–листопаді 2026 (див. розділ 5.3) |
| Події | немає — їх додають під час демонстрації |

Повторний запуск `npm run db:seed` видаляє демо-вчительку з усіма її даними і створює заново — так після демонстрації повертається початковий стан.

**Дати демо-даних і «сьогодні».** Демо-дані прив’язані до жовтня–листопада 2026 р., а зміни тижневого розкладу діють від сьогоднішньої дати. Показ у жовтні 2026 р. до 20 жовтня (сценарій звірено 7 жовтня) потрапляє в першу версію «Моїх уроків», яка діє до 20 жовтня: з 21 жовтня вже записано наступну версію. Тому урок, доданий у тижневий розклад під час показу, з’явиться в календарі лише до 20 жовтня, а з 21 жовтня — ні (докладно — розділ 6). Після 20 жовтня розділи 5.3 і 6 треба перечитати заново: частина готових правок опиниться в минулому, а «сьогодні» — вже в другій версії розкладу.

## 2. Як створити користувача

Сторінки реєстрації в застосунку немає навмисно: застосунок розрахований на одну вчительку, і обліковий запис створюється з командного рядка.

| Спосіб | Команда | Результат |
|---|---|---|
| Демо-вчителька з даними | `npm run db:seed` | Обліковий запис `demo@teachers.local` / `demo-password-1` (або значення `SEED_USER_EMAIL` / `SEED_USER_PASSWORD` з `.env`) разом із готовим навчальним роком і розкладом |
| Справжня вчителька, без даних | `npm run teacher -- create olena@example.com --name "Олена Шевченко"` | Порожній обліковий запис: після входу застосунок одразу відкриє налаштування навчального року, і решта сторінок відкриється лише після нього (розділ 7.1). Ім’я можна не задавати — тоді ім’ям стане пошта |

Команда `npm run teacher` двічі запитає пароль; під час введення символи на екрані не з’являються. Якщо додати `--generate`, пароль вигадає сама команда й покаже його один раз. Пароль ніколи не передається в самій команді й не береться з файлу `.env`. Якщо така пошта вже зареєстрована, команда завершиться помилкою й нічого не змінить.

Тією самою командою керують обліковим записом надалі:

| Що потрібно | Команда | Результат |
|---|---|---|
| Змінити пароль | `npm run teacher -- password olena@example.com` | Діє лише новий пароль; на всіх пристроях, де вчителька була в застосунку, доведеться увійти знову |
| Тимчасово закрити доступ | `npm run teacher -- deactivate olena@example.com` | Вчителька не може увійти, а там, де вона вже була в застосунку, її поверне на сторінку входу. Розклад, події та всі інші її дані залишаються на місці |
| Повернути доступ | `npm run teacher -- activate olena@example.com` | Вчителька входить зі своїм паролем і бачить усе так, як залишила |
| Переглянути всіх | `npm run teacher -- list` | Пошта, ім’я, чи відкритий доступ і коли створено обліковий запис |

Коли доступ закрито, сторінка входу відповідає так само, як на неправильний пароль, — вона не повідомляє, що такий обліковий запис існує.

## 3. Вхід і вихід

| Шлях | Дія | Результат |
|---|---|---|
| `/` або будь-яка сторінка застосунку | Відкрити, не ввійшовши | Перенаправлення на `/sign-in` — сторінку «Вхід. Щоденник учителя» |
| `/sign-in` | Натиснути «Увійти» з порожніми полями | Під полями — підказки про те, що їх треба заповнити |
| `/sign-in` | Ввести неправильний пароль | Повідомлення «Неправильна електронна пошта або пароль»; введена пошта залишається в полі |
| `/sign-in` | Помилитися з паролем п’ять разів поспіль, потім спробувати ще раз | П’ята помилка ще отримує звичайну відповідь, шоста спроба — «Забагато спроб входу. Спробуйте ще раз через N хв.»: вхід закрито до кінця 15 хвилин, відлічених від першої помилки. **Під час показу не відтворювати**: обмеження діє для всієї адреси, з якої заходять, зокрема й для правильного пароля |
| `/sign-in` | Ввести `demo@teachers.local` і `demo-password-1`, натиснути «Увійти» | Кнопка показує «Входимо…», далі відкривається календар на сьогоднішньому дні |
| будь-яка сторінка | Натиснути «Вийти» внизу бічної панелі (на телефоні — у меню «Меню» вгорі екрана) | Сеанс завершено, відкривається `/sign-in`; повернутися кнопкою «Назад» до даних не вийде |

## 5. Календар

Адреса календаря — `/calendar/<вигляд>/<дата>`, де вигляд — `day`, `week`, `month` або `year`, а дата — у форматі `РРРР-ММ-ДД`. Додаток `?schedule=class` перемикає на «Уроки класу». Уся адреса описує екран повністю, тож будь-який стан можна відкрити посиланням або закладкою.

### 5.1 Перегляд і перемикання

| Шлях | Дія | Результат |
|---|---|---|
| `/calendar/day/2026-10-13` | Відкрити | «Вівторок, 13 жовтня 2026 р.»; позначка тижня (чисельник/знаменник); уроки з номером і часом дзвінка; урок 2 — «Алгебра (контрольна) · 9-А» з позначкою «правка» |
| будь-який вигляд | Натиснути «←» / «→» | Попередній / наступний день, тиждень, місяць або рік залежно від вигляду |
| будь-який вигляд | Натиснути «Сьогодні» | Той самий вигляд на сьогоднішній даті; сьогоднішній день позначено «сьогодні» |
| будь-який вигляд | Перемикач «День / Тиждень / Місяць / Рік» | Той самий день у іншому вигляді |
| `/calendar/week/2026-10-19` | Відкрити | «Тиждень 19 жовтня — 25 жовтня 2026 р.»: сім днів, у кожному — уроки та парність тижня |
| `/calendar/month/2026-10-01` | Відкрити | Сітка жовтня: у клітинці — уроки дня («1 · Математика») і події; неробочі дні затінено, назва свята чи канікул написана просто в клітинці, напр. «День захисників і захисниць України» |
| `/calendar/month/2026-10-01` | Натиснути будь-де в клітинці дня — на число, на урок чи на порожнє місце | Відкривається цей день у вигляді «День» |
| `/calendar/year/2026-09-01` | Відкрити | «Навчальний рік: 1 вересня 2026 р. — 31 травня 2027 р.» — усі місяці року, канікули й вихідні затінено; підказка при наведенні на день, напр. «12 жовтня — уроків: 2», «14 жовтня — День захисників і захисниць України» |
| `/calendar/year/2026-09-01` | Натиснути назву місяця / день | Відкривається місяць / день |
| будь-який вигляд | «Швидкі переходи»: «Весь навчальний рік», «До вересня» (або «На початок року»), «Кінець навчального року» | Рік цілком; перший місяць року; останній місяць року |
| будь-який вигляд | Перемикач «Розклад»: «Мої уроки» / «Уроки класу» | Показує власні уроки вчительки або уроки її класу; вибір зберігається при переході між днями й виглядами |
| `/calendar/day/2026-10-12?schedule=class` | Відкрити | Уроки 7-А з ПІБ учителя й кнопкою «Посилання на Zoom»; уроки, які веде сама вчителька, позначено «веду я». Приклад примітки до уроку — 22.10 (розділ 5.3) |

### 5.2 Особливі дні, які варто показати

| Шлях | Що показати | Результат |
|---|---|---|
| `/calendar/day/2026-10-14` | Державне свято | «День захисників і захисниць України», уроків немає |
| `/calendar/week/2026-10-26` | Тиждень канікул | Усі сім днів — «Осінні канікули» |
| `/calendar/day/2026-10-16` | П’ятниця до канікул | День без уроків (методичний день) |
| `/calendar/day/2026-11-06` | П’ятниця після канікул | Правило вже не діє — уроки є |
| `/calendar/week/2026-10-19` | Зміна тижневого розкладу посеред тижня | Пн–Вт за старою версією розкладу, з середи 21.10 — за новою |
| `/calendar/week/2026-11-02` і `/calendar/week/2026-11-09` | Перезапуск відліку чисельника/знаменника з 4 листопада | Парність тижнів відраховується від нової точки |
| `/calendar/week/2026-10-19?schedule=class` | Проміжок у розкладі класу | З 21.10 уроків класу немає (розклад класу на цей час не заданий), крім однієї правки 22.10 |

### 5.3 Правки окремих днів (готові записи з демо-даних)

| Шлях | Що видно |
|---|---|
| `/calendar/day/2026-10-13` | Урок 2 — «правка»: «Алгебра (контрольна) · 9-А» |
| `/calendar/day/2026-10-17` | Субота (вихідний), але є відпрацювання — урок 3 «Відпрацювання · 7-А» |
| `/calendar/day/2026-10-19` | Урок 1 «скасовано» — видно закресленим |
| `/calendar/day/2026-10-22?schedule=class` | Урок 1 — «Виховна година · Шевченко О. П.», примітка «замість уроків» |
| `/calendar/day/2026-11-05` | Урок 2 — «заміна»: «Фізика · 8-А», поруч видно, який урок замінено |
| `/calendar/day/2026-11-09?schedule=class` | Урок 2 класу скасовано; у «Моїх уроках» того ж дня урок 2 залишився |
| `/calendar/day/2026-11-10` | Заміна на номері, де за розкладом уроку не було: «Хімія · 8-А» |
| `/calendar/day/2026-11-12?schedule=class` | Скасування на номері, де за розкладом нічого немає: у календарі лише «Уроків немає». Сам запис видно на сторінці уроку 3 (`/calendar/day/2026-11-12/lesson/3?schedule=class`) — там є кнопка «Повернути урок» |

### 5.4 Редагування одного дня

Змінювати урок можна з виглядів «День» і «Тиждень». Зміна стосується лише однієї дати; тижневий розклад і інші дні не змінюються.

| Шлях | Дія | Результат |
|---|---|---|
| `/calendar/day/<дата>` | Біля уроку натиснути «Змінити» | Відкривається `/calendar/day/<дата>/lesson/<номер>` — «Урок N — <день тижня>, <дата>» з блоками «Зараз у календарі», «За тижневим розкладом» і «Що поставити на цю дату» |
| `/calendar/day/<дата>` | У рядку «Додати урок:» натиснути номер вільного уроку | Той самий екран для порожнього номера |
| `.../lesson/<номер>` | Подивитися на форму | Поля вже заповнено уроком, який зараз стоїть у календарі; «Зберегти» приглушена, доки нічого не змінено, а натискання на неї пояснює: «Немає змін, які треба зберегти» |
| `.../lesson/<номер>` | Почати вводити предмет, клас чи ПІБ учителя | Під полем — підказки зі значень, уже введених раніше (предмети, класи, вчителі) |
| `.../lesson/<номер>` | «Тип запису» — «Правка», заповнити предмет і клас (для «Уроків класу» — предмет, ПІБ учителя, Zoom, додаткова інформація), «Зберегти» | Сторінка уроку залишається відкритою; у блоці «Зараз у календарі» і в календарі на цю дату — новий урок із позначкою «правка» |
| `.../lesson/<номер>` | «Тип запису» — «Заміна», заповнити, «Зберегти» | Урок із позначкою «заміна», поруч видно, який урок замінено |
| `.../lesson/<номер>` | Зберегти з порожнім предметом або класом | Підказка «Вкажіть предмет» / «Вкажіть клас» (для класу — «Вкажіть ПІБ учителя») |
| `.../lesson/<номер>` | Ввести посилання на Zoom без `http://` / `https://` (напр. `zoom.us/j/1`) | Форма не надсилається: браузер сам просить ввести повну адресу. Повідомлення застосунку «Посилання має починатися з http:// або https://» з’являється для адреси з іншим початком, напр. `ftp://…` |
| `.../lesson/<номер>` | «Скасувати урок» | Урок залишається в календарі закресленим, з позначкою «скасовано». Урок із тижневого розкладу скасовується без підтвердження; якщо на цю дату вже була правка або заміна (напр. 13.10), спершу питається «Скасувати урок? Те, що ви вписали на цю дату, буде втрачено — повернути його не вийде.» |
| `.../lesson/<номер>` з правкою | «Прибрати правку» / «Прибрати заміну», підтвердити | На дату повертається урок із тижневого розкладу (або урок зникає, якщо в розкладі його немає — про це попереджає підказка) |
| `.../lesson/<номер>` зі скасуванням | «Повернути урок», підтвердити («Прибрати цей запис? На цю дату знову діятиме тижневий розклад.») | Урок із тижневого розкладу знову діє |
| `.../lesson/<номер>` | «Повернутися до календаря» | Повернення до того вигляду й дати, з яких прийшли |

### 5.5 Події в календарі

| Шлях | Дія | Результат |
|---|---|---|
| `/calendar/day/<дата>` з подією | Подивитися блок «Події» | Завдання з терміном (◷) та інформаційні події (•); прострочені завдання позначено «прострочено» |
| `/calendar/day/<дата>` із завданням | «Позначити виконаним» / «Зняти позначку» | Позначка виконання змінюється; виконане завдання вже не рахується простроченим |
| `/calendar/month/<дата>` | Подивитися на клітинку | Події дня прямо в клітинці (◷ / •), прострочені — червоним |
| `/calendar/year/<дата>` | Навести на день | Підказка з кількістю уроків і подій, напр. «9 жовтня — уроків немає · подій: 2» |

## 6. Тижневий розклад — `/schedule`

Адреса: `/schedule?view=OWN|CLASS&parity=NUMERATOR|DENOMINATOR&day=MON…SUN` (`day` діє лише на вузькому екрані). Кожна зміна діє **від сьогодні й уперед**: попередній розклад залишається для днів, що вже минули.

**Увага щодо демо-даних.** «Мої уроки» мають наступну версію розкладу, що починається 21 жовтня 2026 р. Зміна, збережена раніше за цю дату, потрапляє в чинну версію (з сьогодні до 20 жовтня) і не переходить у наступну: у календарі новий урок буде видно лише до 20 жовтня включно. «Уроки класу» так само: чинна версія діє до 20 жовтня, наступна — з 2 листопада.

| Шлях | Дія | Результат |
|---|---|---|
| `/schedule` | Відкрити | «Тижневий розклад»: мої уроки, чисельник. На широкому екрані — усі сім днів одразу, у кожного дня свої рядки за розкладом дзвінків («1 · 08:30») і своя кнопка «Зберегти» |
| `/schedule`, вузьке вікно або телефон | Відкрити | Перемикач днів «Пн…Нд» і форма одного дня (за замовчуванням — сьогоднішнього) |
| `/schedule` | Перемикачі «Мої уроки / Уроки класу», «Чисельник / Знаменник» | Показує відповідний тиждень |
| `/schedule?view=OWN&parity=NUMERATOR` | У формі «Понеділок» заповнити «Урок 3, предмет» і «Урок 3, клас», «Зберегти» цього дня | Урок з’являється в календарі на понеділки-чисельники — від сьогодні до 20 жовтня (див. увагу вище; напр. `/calendar/day/2026-10-12`). «Чинний розклад» тепер починається сьогодні, а попередній закінчується вчора й показаний у списку нижче |
| `/schedule` | Подивитися на кнопки «Зберегти» | Приглушені, доки в цьому дні нічого не змінено; натискання пояснює «Немає змін, які треба зберегти» |
| `/schedule` | Почати вводити предмет або клас | Підказки зі значень, уже введених раніше |
| `/schedule?view=CLASS&...` | Заповнити предмет, ПІБ учителя, посилання на Zoom, додаткову інформацію, «Зберегти» | Урок класу в розкладі та в календарі з перемикачем «Уроки класу» |
| `/schedule` | Очистити обидва поля рядка, «Зберегти» | Урок прибрано з розкладу від сьогодні |
| `/schedule` | Заповнити лише предмет | Підказка «Вкажіть клас» (для класу — «Вкажіть ПІБ учителя») |
| `/schedule` | Блок «Дія розкладу» | «Чинний розклад: з … до …»; попередження, до якої дати діятиме старий розклад, якщо зберегти зміну сьогодні; список інших версій, напр. «з 21 жовтня 2026 р. до 24 грудня 2026 р. — починає діяти пізніше» |
| `/schedule` | «Скопіювати з чисельника у знаменник» (або навпаки), підтвердити («Скопіювати весь тиждень?…») | Тиждень-приймач повністю замінено уроками тижня-джерела |
| `/schedule` | «Доки діє цей розклад»: «Діє» — «До вибраної дати», «Останній день дії» напр. 16 жовтня, «Змінити межу» | «Чинний розклад: … до 16 жовтня»; у календарі 19–20 жовтня уроків за цим розкладом немає. «До найближчих канікул» і «До кінця семестру» на демо-даних нічого не змінять: розклад не може діяти довше, ніж до 20 жовтня, бо з 21 жовтня починається наступний, — про це каже підказка в блоці «Дія розкладу» |
| `/schedule` | Прочитати підказку про минулі дні | Змінити минулий день через шаблон не можна — для цього є редагування дня в календарі (розділ 5.4) |

## 7. Навчальний рік — `/year`

Адреса: `/year?year=<ідентифікатор>`; перемикач років угорі сторінки з’являється, коли років більше одного. Усе, крім дзвінків, належить вибраному навчальному року. Форми збережених записів відкриваються з приглушеною «Зберегти» — вона стає доступною, щойно щось змінено.

### 7.1 Перше налаштування (новий обліковий запис)

Показується на порожньому обліковому записі (розділ 2), не на демо-вчительці.

| Шлях | Дія | Результат |
|---|---|---|
| будь-яка сторінка | Увійти вперше | Відкривається `/year`; «Календар», «Розклад» і «Події» перенаправляють сюди ж, у меню лише «Навчальний рік» |
| `/year` | Подивитися вгорі сторінки | «Спершу налаштуйте навчальний рік» — чотири пункти з позначкою «є» / «ще бракує»: перший і останній день року; з чого починається рік; обидва семестри; розклад дзвінків хоча б для одного уроку. Канікули й дні без уроків можна додати пізніше |
| `/year` | «Наступний крок: …» — «Перейти» | Сторінка прокручується до розділу, який треба заповнити наступним |
| `/year` | Заповнити рік, обидва семестри, дзвінки | Після кожного кроку позначка змінюється на «є», а «Наступний крок» — на наступний пункт. Після останнього — «Календар, розклад і події тепер відкриті. Далі заповніть тижневий розклад уроків…», і меню показує всі пункти |

### 7.2 Розділи сторінки

| Шлях | Дія / розділ | Результат |
|---|---|---|

## 9. Рекомендований порядок показу (≈ 20 хвилин)

1. **Вхід** (`/sign-in`) з неправильним, потім із правильним паролем.
2. **Календар сьогодні** — вигляди «День → Тиждень → Місяць → Рік», «Сьогодні», швидкі переходи.
3. **Жовтень 2026** (`/calendar/month/2026-10-01`) — свято 14.10, осінні канікули, вихідні.
4. **Мої уроки / Уроки класу** (`/calendar/day/2026-10-12`, потім `?schedule=class`) — «веду я», посилання на Zoom.
5. **Готові правки** — 13.10 (правка), 19.10 (скасування), 5.11 (заміна), 17.10 (відпрацювання в суботу).
6. **Своя правка** — відкрити день у календарі, «Змінити» урок, зберегти заміну, потім «Прибрати заміну».
7. **Тижневий розклад** (`/schedule`) — додати урок і показати його в календарі до 20.10 (розділ 6, увага), показати «Дія розкладу», скопіювати чисельник у знаменник.
8. **Навчальний рік** (`/year`) — додати позаплановий вихідний і показати його в календарі.
9. **Події** (`/events`) — завдання з терміном і щотижнева подія; позначити завдання виконаним у календарі.
10. **Вихід** — «Вийти».
11. *(за потреби)* **Перший вхід нової вчительки** — окремий порожній обліковий запис (розділ 2) і налаштування року з підказками (розділ 7.1).

Після демонстрації: `npm run db:seed` повертає демо-дані до початкового стану.
