# Сценарій демонстрації для вчителя

Покроковий перелік того, що можна показати вчителеві в поточній версії «Щоденника учителя»: на якій сторінці, що зробити і що має з’явитися на екрані. Документ складено за специфікацією (`docs/specs/specification.md`) і за тим, що реально є в коді на момент написання.

Адреси сторінок нижче вказано відносно адреси застосунку — локально це `http://localhost:3000`.

---

## 1. Підготовка (робить той, хто проводить демонстрацію)

```sh
cp .env.example .env          # і задати BETTER_AUTH_SECRET: openssl rand -base64 32
npm install
docker compose up -d          # база даних PostgreSQL
npm run db:migrate            # створити таблиці
npm run db:seed               # демо-вчителька та готовий набір даних
npm run dev                   # http://localhost:3000
```

Поки `BETTER_AUTH_SECRET` має значення `replace-me`, увійти не вийде.

**Що кладе в базу `npm run db:seed`** (докладно — `docs/architecture/design/expand-fixtures.md` §3):

| Що | Значення |
|---|---|
| Вчителька | «Ковальчук М. І.», пошта `demo@teachers.local`, пароль `demo-password-1` |
| Навчальний рік | 1 вересня 2026 — 31 травня 2027, починається з чисельника |
| Семестри | І: 1.09.2026 — 24.12.2026; ІІ: 12.01.2027 — 31.05.2027 |
| Неробочі дні | 14 жовтня — «День захисників і захисниць України»; 26 жовтня — 1 листопада — «Осінні канікули» |
| Дні тижня без уроків | п’ятниця до осінніх канікул (методичний день); субота й неділя — весь рік |
| Дзвінки | уроки 1–5: 08:30, 09:25, 10:25, 11:20, 12:15 |
| Відлік парності | від 1 вересня (чисельник) і повторно з 4 листопада (чисельник) |
| Тижневий розклад | «Мої уроки» — дві версії (зміна з 21 жовтня); «Уроки класу» 7-А — дві версії з проміжком 21 жовтня — 1 листопада |
| Правки окремих днів | 8 записів у жовтні–листопаді 2026 (див. розділ 5.3) |
| Події | немає — їх додають під час демонстрації |

Повторний запуск `npm run db:seed` видаляє демо-вчительку з усіма її даними і створює заново — так після демонстрації повертається початковий стан.

## 2. Як створити користувача

Сторінки реєстрації в застосунку немає навмисно: застосунок розрахований на одну вчительку, і обліковий запис створюється з командного рядка.

| Спосіб | Команда | Результат |
|---|---|---|
| Демо-вчителька з даними | `npm run db:seed` | Обліковий запис `demo@teachers.local` / `demo-password-1` (або значення `SEED_USER_EMAIL` / `SEED_USER_PASSWORD` з `.env`) разом із готовим навчальним роком і розкладом |
| Справжня вчителька, без даних | `TEACHER_EMAIL=... TEACHER_PASSWORD=... TEACHER_NAME="..." npm run create-teacher` | Порожній обліковий запис: після входу календар підкаже спершу налаштувати навчальний рік. `TEACHER_NAME` можна не задавати — тоді ім’ям стане пошта |

`npm run create-teacher` читає змінні також із файлу `.env`. Якщо така пошта вже зареєстрована, команда завершиться помилкою.

## 5. Календар

Адреса календаря — `/calendar/<вигляд>/<дата>`, де вигляд — `day`, `week`, `month` або `year`, а дата — у форматі `РРРР-ММ-ДД`. Додаток `?schedule=class` перемикає на «Уроки класу». Уся адреса описує екран повністю, тож будь-який стан можна відкрити посиланням або закладкою.

### 5.1 Перегляд і перемикання

| Шлях | Дія | Результат |
|---|---|---|
| `/calendar/day/2026-10-13` | Відкрити | «Вівторок, 13 жовтня 2026 р.»; позначка тижня (чисельник/знаменник); уроки з номером і часом дзвінка; урок 2 — «Алгебра (контрольна) · 9-А» з позначкою «правка» |
| будь-який вигляд | Натиснути «←» / «→» | Попередній / наступний день, тиждень, місяць або рік залежно від вигляду |
| будь-який вигляд | Натиснути «Сьогодні» | Той самий вигляд на сьогоднішній даті; сьогоднішній день позначено «сьогодні» |
| будь-який вигляд | Перемикач «День / Тиждень / Місяць / Рік» | Той самий день у іншому вигляді |
| `/calendar/week/2026-10-19` | Відкрити | «Тиждень 19 жовтня — 25 жовтня 2026 р.»: сім днів, у кожному — уроки та парність тижня |
| `/calendar/month/2026-10-01` | Відкрити | Сітка жовтня: у клітинках — кількість уроків, неробочі дні затінено; підказка при наведенні, напр. «14 жовтня — День захисників і захисниць України» |
| `/calendar/month/2026-10-01` | Натиснути на клітинку дня | Відкривається цей день у вигляді «День» |
| `/calendar/year/2026-09-01` | Відкрити | «Навчальний рік: 1 вересня 2026 р. — 31 травня 2027 р.» — усі місяці року, канікули й вихідні затінено |
| `/calendar/year/2026-09-01` | Натиснути назву місяця / день | Відкривається місяць / день |
| будь-який вигляд | «Швидкі переходи»: «Весь навчальний рік», «До вересня» (або «На початок року»), «Кінець навчального року» | Рік цілком; перший місяць року; останній місяць року |
| будь-який вигляд | Перемикач «Розклад»: «Мої уроки» / «Уроки класу» | Показує власні уроки вчительки або уроки її класу; вибір зберігається при переході між днями й виглядами |
| `/calendar/day/2026-10-12?schedule=class` | Відкрити | Уроки 7-А з ПІБ учителя, кнопкою «Посилання на Zoom» і приміткою; уроки, які веде сама вчителька, позначено «веду я» |

### 5.2 Особливі дні, які варто показати

| Шлях | Що показати | Результат |
|---|---|---|
| `/calendar/day/2026-10-14` | Державне свято | «День захисників і захисниць України», уроків немає |
| `/calendar/week/2026-10-26` | Тиждень канікул | Усі сім днів — «Осінні канікули» |
| `/calendar/day/2026-10-16` | П’ятниця до канікул | День без уроків (методичний день) |
| `/calendar/day/2026-11-06` | П’ятниця після канікул | Правило вже не діє — уроки є |
| `/calendar/week/2026-10-19` | Зміна тижневого розкладу посеред тижня | Пн–Вт за старою версією розкладу, з середи 21.10 — за новою |
| `/calendar/week/2026-11-02` і `/calendar/week/2026-11-09` | Перезапуск відліку чисельника/знаменника з 4 листопада | Парність тижнів відраховується від нової точки |
| `/calendar/week/2026-10-19?schedule=class` | Проміжок у розкладі класу | З 21.10 уроків класу немає (розклад класу на цей час не заданий), крім однієї правки 22.10 |

### 5.3 Правки окремих днів (готові записи з демо-даних)

| Шлях | Що видно |
|---|---|
| `/calendar/day/2026-10-13` | Урок 2 — «правка»: «Алгебра (контрольна) · 9-А» |
| `/calendar/day/2026-10-17` | Субота (вихідний), але є відпрацювання — урок 3 «Відпрацювання · 7-А» |
| `/calendar/day/2026-10-19` | Урок 1 «скасовано» — видно закресленим |
| `/calendar/day/2026-10-22?schedule=class` | Урок 1 — «Виховна година · Шевченко О. П.», примітка «замість уроків» |
| `/calendar/day/2026-11-05` | Урок 2 — «заміна»: «Фізика · 8-А», поруч видно, який урок замінено |
| `/calendar/day/2026-11-09?schedule=class` | Урок 2 класу скасовано; у «Моїх уроках» того ж дня урок 2 залишився |
| `/calendar/day/2026-11-10` | Заміна на номері, де за розкладом уроку не було: «Хімія · 8-А» |
| `/calendar/day/2026-11-12?schedule=class` | Скасування на номері, де за розкладом нічого немає |

### 5.4 Редагування одного дня

Змінювати урок можна з виглядів «День» і «Тиждень». Зміна стосується лише однієї дати; тижневий розклад і інші дні не змінюються.

| Шлях | Дія | Результат |
|---|---|---|
| `/calendar/day/<дата>` | Біля уроку натиснути «Змінити» | Відкривається `/calendar/day/<дата>/lesson/<номер>` — «Урок N — <день тижня>, <дата>» з блоками «Зараз у календарі», «За тижневим розкладом» і «Що поставити на цю дату» |
| `/calendar/day/<дата>` | У рядку «Додати урок:» натиснути номер вільного уроку | Той самий екран для порожнього номера |
| `.../lesson/<номер>` | «Тип запису» — «Правка», заповнити предмет і клас (для «Уроків класу» — предмет, ПІБ учителя, Zoom, додаткова інформація), «Зберегти» | У календарі на цю дату — новий урок із позначкою «правка» |
| `.../lesson/<номер>` | «Тип запису» — «Заміна», заповнити, «Зберегти» | Урок із позначкою «заміна», поруч видно, який урок замінено |
| `.../lesson/<номер>` | Зберегти з порожнім предметом або класом | Підказка «Вкажіть предмет» / «Вкажіть клас» (для класу — «Вкажіть ПІБ учителя») |
| `.../lesson/<номер>` | Ввести посилання на Zoom без `http://` / `https://` | Підказка «Посилання має починатися з http:// або https://» |
| `.../lesson/<номер>` | «Скасувати урок», підтвердити | Урок залишається в календарі закресленим, з позначкою «скасовано». Якщо на цю дату вже була правка — попередження, що вписане буде втрачено |
| `.../lesson/<номер>` з правкою | «Прибрати правку» / «Прибрати заміну», підтвердити | На дату повертається урок із тижневого розкладу (або урок зникає, якщо в розкладі його немає — про це попереджає підказка) |
| `.../lesson/<номер>` зі скасуванням | «Повернути урок» | Урок із тижневого розкладу знову діє |
| `.../lesson/<номер>` | «Повернутися до календаря» | Повернення до того вигляду й дати, з яких прийшли |
| `/calendar/day/<дата>` на обліковому записі без дзвінків | Подивитися на екран | «Щоб додати урок, спершу заповніть розклад дзвінків — Розклад дзвінків» (посилання на `/year`) |

### 5.5 Події в календарі

| Шлях | Дія | Результат |
|---|---|---|
| `/calendar/day/<дата>` з подією | Подивитися блок «Події» | Завдання з терміном (◷) та інформаційні події (•); прострочені завдання позначено «прострочено» |
| `/calendar/day/<дата>` із завданням | «Позначити виконаним» / «Зняти позначку» | Позначка виконання змінюється; виконане завдання вже не рахується простроченим |
| `/calendar/month/<дата>` | Навести на день | Підказка з кількістю уроків, подій і прострочених |

## 6. Тижневий розклад — `/schedule`

Адреса: `/schedule?view=OWN|CLASS&parity=NUMERATOR|DENOMINATOR&day=MON…SUN`. Кожна зміна діє **від сьогодні й уперед**: попередній розклад залишається для днів, що вже минули.

| Шлях | Дія | Результат |
|---|---|---|
| `/schedule` | Відкрити | «Тижневий розклад»: мої уроки, чисельник, сьогоднішній день тижня; огляд тижня та форма дня з рядками за розкладом дзвінків |
| `/schedule` | Перемикачі «Мої уроки / Уроки класу», «Чисельник / Знаменник», дні «Пн…Нд» | Показує відповідний тиждень і день |
| `/schedule?view=OWN&parity=NUMERATOR&day=MON` | Заповнити «Урок N, предмет» і «Урок N, клас», «Зберегти» | Урок з’являється в огляді тижня і в календарі — від сьогодні на всі такі дні |
| `/schedule?view=CLASS&...` | Заповнити предмет, ПІБ учителя, посилання на Zoom, додаткову інформацію, «Зберегти» | Урок класу в розкладі та в календарі з перемикачем «Уроки класу» |
| `/schedule` | Очистити всі поля рядка, «Зберегти» | Урок прибрано з розкладу від сьогодні |
| `/schedule` | Заповнити лише предмет | Підказка «Вкажіть клас» (для класу — «Вкажіть ПІБ учителя») |
| `/schedule` | Блок «Дія розкладу» | «Чинний розклад: з … до …», попередження, до якої дати діятиме старий розклад після збереження, список «Попередні розклади» |
| `/schedule` | «Скопіювати з чисельника у знаменник» (або навпаки), підтвердити | Тиждень-приймач повністю замінено уроками тижня-джерела |
| `/schedule` | «Доки діє цей розклад»: «До кінця семестру» / «До найближчих канікул» / «До вибраної дати» + «Останній день дії», «Змінити межу» | Змінюється дата, до якої діє розклад; у календарі після неї уроків за цим розкладом немає |
| `/schedule` на обліковому записі без дзвінків | Відкрити | «Спершу заповніть розклад дзвінків» з посиланням на `/year` |
| `/schedule` | Прочитати підказку про минулі дні | Змінити минулий день через шаблон не можна — для цього є редагування дня в календарі (розділ 5.4) |

## 7. Навчальний рік — `/year`

Адреса: `/year?year=<ідентифікатор>`; перемикач років угорі сторінки. Усе, крім дзвінків, належить вибраному навчальному року.

| Шлях | Дія / розділ | Результат |
|---|---|---|
| `/year` без років | Відкрити | «Навчальних років ще немає. Додайте перший…» і форма «Новий навчальний рік» |
| `/year` | «Новий навчальний рік»: «Перший день року», «Останній день року», «Рік починається з» (чисельник/знаменник), «Додати» | Рік створено; з’являються решта розділів; у календарі — межі року |
| `/year` | Додати рік, що перетинається з наявним | Помилка «Ці дати перетинаються з іншим навчальним роком» |
| `/year` | «Межі навчального року» — змінити дати, «Зберегти» | Межі оновлено |
| `/year` | «Межі навчального року» — «Видалити», підтвердити | Рік видалено разом із семестрами, канікулами, правилами і точками відліку |
| `/year` | «Семестри»: «Семестр» (Перший/Другий), «Перший день», «Останній день», «Додати» / «Зберегти» / «Видалити» | Семестр додано, змінено або видалено; від нього залежить межа «До кінця семестру» |
| `/year` | «Канікули, свята та інші неробочі дні»: вид («Канікули» / «Державне свято» / «Позаплановий вихідний»), назва, дати, «Додати» | Дні затінено в календарі й підписано назвою; уроків у них немає |
| `/year` | «Дні тижня без уроків»: день тижня, «Діє» («До вибраної дати» / «До найближчих канікул» / «До кінця семестру»), «Додати» | Цей день тижня стає вільним від уроків до вказаної межі. Без правил уроки можливі всі сім днів, зокрема субота й неділя |
| `/year` | «Розклад дзвінків»: початок і кінець уроків 0–9, «Зберегти» | Номери й час уроків у календарі та розкладі; порожній рядок — такого уроку немає. Дзвінки спільні для всіх років |

## 9. Рекомендований порядок показу (≈ 20 хвилин)

1. **Вхід** (`/sign-in`) з неправильним, потім із правильним паролем.
2. **Календар сьогодні** — вигляди «День → Тиждень → Місяць → Рік», «Сьогодні», швидкі переходи.
3. **Жовтень 2026** (`/calendar/month/2026-10-01`) — свято 14.10, осінні канікули, вихідні.
4. **Мої уроки / Уроки класу** (`/calendar/day/2026-10-12`, потім `?schedule=class`) — «веду я», посилання на Zoom.
5. **Готові правки** — 13.10 (правка), 19.10 (скасування), 5.11 (заміна), 17.10 (відпрацювання в суботу).
6. **Своя правка** — відкрити день у календарі, «Змінити» урок, зберегти заміну, потім «Прибрати заміну».
7. **Тижневий розклад** (`/schedule`) — додати урок, показати «Дія розкладу», скопіювати чисельник у знаменник.
8. **Навчальний рік** (`/year`) — додати позаплановий вихідний і показати його в календарі.
9. **Події** (`/events`) — завдання з терміном і щотижнева подія; позначити завдання виконаним у календарі.
10. **Вихід** — «Вийти».

Після демонстрації: `npm run db:seed` повертає демо-дані до початкового стану.
